# 双目 Deflectometry (相位偏折测量) 三维重建仿真 - 参数说明

## 一、Deflectometry 原理

**与传统结构光的区别**:
- 传统结构光: 投影仪→物体散射→相机, 用视差三角测量
- **Deflectometry**: 显示屏→镜面物体反射→相机, 通过相位得到显示屏坐标, 利用反射几何重建

**光路**:
```
显示屏点 S → 镜面物体表面点 P → 反射 → 相机光心 O
```

**反射几何**:
- 入射方向: i = normalize(P - S)  (显示屏→表面)
- 反射方向: r = normalize(O - P)  (表面→相机)
- 法向量:   N = normalize(i + r)  (入射角=反射角)

## 二、双目 Deflectometry 重建算法

**核心思想**: 两个相机观察同一镜面表面点 P, 各自看到不同的显示屏区域, 通过法向量一致性约束求解 P 的深度。

```
对左相机每个有效像素 (u_L, v_L):
  1. 由相位获取显示屏坐标 (xS_L, yS_L) → 显示屏3D点 S_L
     - 纵向条纹相位 → 显示屏 x 坐标
     - 横向条纹相位 → 显示屏 y 坐标
  2. 左相机射线: P(t) = t * d_L  (光心在原点)
  3. 深度搜索 t (粗搜+精搜):
     a. P = t * d_L
     b. 投影 P 到右相机 → (u_R, v_R)
     c. 由右相机相位获取显示屏点 S_R
     d. 计算左右法向量:
        N_L = normalize(normalize(P-S_L) + normalize(O_L-P))
        N_R = normalize(normalize(P-S_R) + normalize(O_R-P))
     e. 一致性: dot = N_L · N_R  (越接近1越好)
  4. 取 dot 最大的 t 作为最优深度
  5. 输出: 表面点 P + 法向量 N
```

## 三、处理流程

```
24幅双目条纹图像 (binocular_deflectometry.py 生成)
  │  (镜面物体反射显示屏的条纹)
  ├── 左相机: pose0_left_img0~23.bmp  (纵向12 + 横向12)
  └── 右相机: pose0_right_img0~23.bmp
       │
       ▼
1. 三频四步多频外差法相位展开 (PhaseUnwrap)
   - 四步相移: tan(φ) = (I4-I2)/(I1-I3)
   - 三频外差: φ12=φ1-φ2, φ23=φ2-φ3, φ123=φ12-φ23
   - 相位展开: 由合成频率反推各频率绝对相位
   - 纵向条纹 → 显示屏 x 坐标
   - 横向条纹 → 显示屏 y 坐标
       │
       ▼
2. 显示屏坐标 → 3D点 (利用投影仪标定参数)
   - 显示屏像素 (xS, yS) → 去畸变归一化 → 投影仪坐标系 → 左相机坐标系
       │
       ▼
3. 双目 Deflectometry 重建 (深度搜索 + 法向量一致性)
   - 对左相机每个像素搜索深度 t
   - 投影到右相机, 获取右显示屏点
   - 法向量一致性 N_L·N_R → 最优化
       │
       ▼
4. 输出: 三维点云 + 法向量 + 深度图 + 法向量图
   - OpenGL 显示 / PLY 保存 (含法向量)
```

## 四、需要已知的参数

### 1. 系统参数 (硬编码在 MainDlg::initSystemParas)

| 参数 | 值 | 说明 | 获取方式 |
|------|-----|------|----------|
| 相机分辨率 | 1440×1080 | Blender 渲染分辨率 | `binocular_deflectometry.py` 的 `setup_render_settings()` |
| 显示屏分辨率 | 1280×800 | 显示条纹图案的显示屏/投影仪分辨率 | 显示屏规格 |
| 频率数 | 3 | 三频 | 设计参数 |
| 相移步数 | 4 | 四步 | 设计参数 |
| 条纹周期 | 13,14,15 (像素) | 三频的条纹周期 | **条纹图案生成脚本** (需与投影图案一致) |
| 条纹偏移 | 20 (像素) | 条纹零位偏移 | 投影图案生成脚本 |
| 测量深度范围 | 180~800 mm | 镜面物体到相机的距离范围 | 系统设计指标/实测 |
| 最大条纹灰度 | 250 | 调制度阈值过滤 | 经验值 |
| 法向量一致性阈值 | 0.999 | N_L·N_R 阈值 | 经验值 (越严格精度越高但点数越少) |
| 粗搜索步数 | 200 | 深度搜索粗采样 | 计算量与精度平衡 |
| 精搜索步数 | 100 | 粗搜后局部精搜 | 计算量与精度平衡 |

### 2. 双目相机标定参数 (cal_res.txt)

格式 (33个数值, 逐行):
```
om(3)           # 右相机相对于左相机的旋转向量 (Rodrigues)
T(3)            # 右相机相对于左相机的平移向量 (mm)
fcLeft(2)       # 左相机焦距 (fx, fy)
ccLeft(2)       # 左相机主点 (cx, cy)
distortLeft(5)  # 左相机畸变 (k1,k2,p1,p2,k3)
fcRight(2)      # 右相机焦距
ccRight(2)      # 右相机主点
distortRight(5) # 右相机畸变
F(9)            # 基本矩阵 3×3
```

**获取方式**: 张正友标定法 + OpenCV `stereoCalibrate()`

### 3. 显示屏标定参数 (cal_Projector.txt) — **Deflectometry关键参数**

格式 (10个数值, 新格式):
```
om(3)           # 显示屏相对于左相机的旋转向量
T(3)            # 显示屏相对于左相机的平移向量 (mm)
psW psH         # 显示屏像素尺寸 (mm/px, 水平/垂直)
prjW prjH       # 显示屏分辨率 (像素)
```

**坐标约定**: 显示屏局部坐标系原点 = 屏左上角(相机视角下图像(0,0)像素处), +X 沿像素 u+ 方向(图像右), +Y 沿像素 v+ 方向(图像下), 屏幕平面 z=0。

**物理意义**: 重建中显示屏像素坐标 → 左相机坐标系 3D 点:
```
局部mm坐标 = (xS * psW, yS * psH, 0)
显示屏3D点 S = R_prj * local^T + T_prj   (左相机坐标系)
```

**旧格式兼容**: 15个数值的旧格式 `om(3) T(3) fcPrj(2) ccPrj(2) distortPrj(5)` 仍可读取,
自动换算: `ps = 1/fc`, `res = round(2*cc)`。

**获取方式**:
- Blender 仿真: 由场景中 `C_Screen` 坐标系空对象相对 `C_LCam` 的位姿直接导出 (binocular_deflectometry.py)
- 实物系统: 标定显示屏平面位姿 (solvePnP) + 已知显示屏物理尺寸与分辨率

### 4. 条纹图案参数 (需与投影图案生成一致)

**关键**: `fringePitches` (条纹周期) 必须与生成 `data/0~23.bmp` 的脚本完全一致。

当前假设 `data/` 目录下的 24 幅图案为:
- 0~3:   纵向条纹 频率1 (周期=13) → 编码显示屏 x 坐标
- 4~7:   纵向条纹 频率2 (周期=14)
- 8~11:  纵向条纹 频率3 (周期=15)
- 12~15: 横向条纹 频率1 → 编码显示屏 y 坐标
- 16~19: 横向条纹 频率2
- 20~23: 横向条纹 频率3

## 五、使用方法

1. **VS2022 打开** `Reconstruct3D.sln` (x64, Release)
2. **编译运行**
3. **加载条纹图像**: 选择 `binocular_deflectometry.py` 输出的 `save2/pose_0` 目录
4. **加载标定参数**: 选择包含 `cal_res.txt` 和 `cal_Projector.txt` 的目录
5. **点击"开始三维重建"**
6. **OpenGL 视图**: 鼠标左键旋转/滚轮缩放/右键平移
7. **保存点云**: 导出 PLY 文件 (含位置+法向量, 可用 MeshLab 查看)

## 六、参数获取总结

| 参数类别 | 获取方法 | 工具 |
|----------|----------|------|
| 相机内参+畸变 | 张正友标定法 | OpenCV calibrateCamera, 棋盘格标定板 |
| 双目外参 (R,T) | 双目立体标定 | OpenCV stereoCalibrate |
| **显示屏内参+外参** | **显示屏-相机联合标定** | 投影棋盘格图案, inverse camera 法 |
| 条纹周期 | 投影图案生成脚本 | 检查 data/ 目录图案 |
| 深度范围 | 标定后实测 | 测量镜面物体到相机的最近/最远距离 |
| 法向量一致性阈值 | 经验值 | 0.999 (可调整) |
